## What was wrong / what was checked

- Baseline: `./gradlew build` on the untouched Initializr skeleton passed before any change.
- jqwik 1.10.1 is built against JUnit Platform 1.14, but Spring Boot 4.1.1 forces JUnit
  6.0.3. Checked with a throwaway property test (one passing, one deliberately failing
  property): jqwik discovered and ran both, and the failing one failed as expected.
  The throwaway test was deleted and is not committed.
- PMD first run: 1 finding, `UncommentedEmptyMethodBody` on `contextLoads()`. Fixed with a
  comment explaining why the body is empty; not suppressed.
- SpotBugs: 0 warnings on main and test.
- `./gradlew clean build`: BUILD SUCCESSFUL, 2 tests, 0 failures, 0 PMD violations.
- `prod` profile started with no `ROSTER_DB_*` variables: the app refuses to start
  (`'url' must start with "jdbc"`), so a missing variable cannot silently fall back to H2.
- Known harmless noise: PMD prints an "auxClasspath" warning about `jrt-fs.jar`; it
  already points at the Temurin 21 JDK used by the toolchain.
